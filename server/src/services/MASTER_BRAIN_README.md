The Master Brain is a centralized AI intelligence system that powers ALL content generation features in InstaMarketing. Instead of having separate, disconnected AI prompts for each feature, the Master Brain provides:

- **One universal content philosophy** that every feature follows
- **Consistent brand voice** across all outputs
- **Proven content structures** based on Instagram best practices
- **Reduced randomness** through specific rules and constraints
- **Reliable, professional outputs** every time

## Universal Content Laws

These 8 laws apply to EVERY piece of content generated:

### 1. Hook First
- First 3 words grab attention
- Never start with "In this post..." or "Today we're going to..."
- Use pattern interrupts, questions, or bold statements

### 2. Clarity Over Cleverness
- Simple words beat complex ones
- One idea per sentence
- If a 12-year-old can't understand it, simplify it

### 3. Emotional Triggers
Every piece triggers ONE primary emotion:
- Curiosity (opens loops)
- FOMO (fear of missing out)
- Aspiration (I want that)
- Validation (I feel seen)
- Surprise (I didn't know that)

### 4. Structure Is Everything
- Hook → Value → CTA (always this order)
- Use line breaks for readability
- Short paragraphs (1-2 sentences max)

### 5. CTA Mastery
- Every piece needs a clear next step
- CTAs must be specific and actionable
- Examples: "Save this ↓", "Drop a 🔥", "Comment YES"

### 6. Brand Voice Consistency
- Match the user's defined tone exactly
- Never mix tones within a single piece

### 7. Length Discipline
| Content Type | Target Length |
|--------------|---------------|
| Captions | 125-200 words |
| Carousel slides | 10-40 words |
| Reel scripts | 60-90 words (30s) |
| Hooks | 3-8 words |
| CTAs | 5-15 words |

### 8. No Filler, No Fluff
- Delete: "very", "really", "just", "actually", "basically"
- Avoid: "I think", "In my opinion", "It's important to note"
- Cut: "a lot of", "some people", "various things"

## Content Structure Templates

### Carousel (7 slides ideal)
```
Slide 1: HOOK (pattern interrupt, 15 words max)
Slide 2: CONTEXT (why this matters, 30 words)
Slides 3-6: VALUE (one point each, 35 words)
Slide 7: CTA (action + follow prompt, 20 words)
```

### Reel Script (30 seconds)
```
0-3s: HOOK (stop the scroll, 5-10 words)
3-8s: CONTEXT (set up value, 15-25 words)
8-25s: VALUE (core content, 30-50 words)
25-30s: CTA (next step, 10-15 words)
```

### Caption (150 words ideal)
```
Line 1: HOOK (visible before "more", 5-12 words)
[blank line]
Body: VALUE (2-4 short paragraphs, 50-100 words)
[blank line]
CTA: ENGAGEMENT PROMPT (10-25 words)
[blank line]
Hashtags: (separate section, 5-15 tags)
```

## Video Intelligence Layer

### Scene Matching Rules
- Each scene: 3-5 seconds for short-form
- Match visual mood to script emotion
- Use variety — don't repeat similar shots
- B-roll enhances, never distracts

### Stock Footage Query Patterns
```
Pattern: [action/subject] + [context/setting] + [mood]

Examples:
✓ "person typing laptop focused"
✓ "sunrise mountain peak"
✓ "team celebrating office"
✗ "success" (too abstract)
✗ "achieving goals" (not searchable)
```

## Using the Master Brain

### Basic Usage

```javascript
const { getPromptForFeature, buildUserContext } = require('./masterBrain');

// Build user context from their brand settings
const userContext = buildUserContext({
  voice: 'professional',
  niche: 'business',
  targetAudience: 'entrepreneurs and business owners'
});

// Get the complete prompt for any feature
const carouselPrompt = getPromptForFeature('carousel', userContext);

// Use with OpenAI
const response = await openai.chat({
  messages: [
    { role: 'system', content: carouselPrompt.system },
    { role: 'user', content: carouselPrompt.template('5 marketing mistakes to avoid', 7) }
  ]
});
```

## Quality Gates

Before any AI output is returned, it must pass these checks:

- [ ] Does it have a strong hook?
- [ ] Is the core message clear?
- [ ] Is there a specific CTA?
- [ ] Does it match the requested tone?
- [ ] Is it the right length?
- [ ] Would YOU engage with this?

## Error Handling

### Missing Information
1. Use smart defaults based on context
2. Never make up specific facts or statistics
3. Use placeholders: `[YOUR PRODUCT]`, `[YOUR RESULT]`
4. Flag assumptions vs. provided info

### Unclear Requests
1. Interpret the most likely intent
2. Provide the best possible output
3. Note any assumptions made
